# Domain Docs

This repository uses one domain context: root `CONTEXT.md` and `docs/adr/`.

## Before exploring

Read `CONTEXT.md` and ADRs in `docs/adr/` relevant to the current work. When these files do not exist, proceed silently; `/domain-modeling` creates them lazily when terms or decisions are resolved.

## Vocabulary

Use the glossary's terms when naming domain concepts in issues, proposals, hypotheses, and tests. Reconsider unfamiliar terms or record real gaps for `/domain-modeling`.

## Decisions

Surface conflicts with existing ADRs explicitly, identifying the decision and the reason to reconsider it.
